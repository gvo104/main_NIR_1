# НИР: стратегии поиска прогностических моделей в LLM-агентных системах

Репозиторий НИР, посвящённой сравнению стратегий поиска в деревьях программ, которые LLM-агент создаёт для задач эпидемиологического прогнозирования.

Цель работы — определить, как политика выбора родительского кандидата, доступный бюджет и свойства дерева влияют на качество лучшей найденной модели. Основной планируемый результат — воспроизводимое offline-сравнение Random, Greedy, ε-greedy и FUTS/PUCT на зафиксированных деревьях кандидатов.

## Структура

- `docs/plan/` — планы следующих этапов и протоколы работ;
- `docs/context/` — журнал принятых решений, допущений, результатов проверок и изменений направления исследования.

## Текущий статус

Репозиторий инициализирован. Детальный рабочий план находится в [docs/plan/plan_1.md](docs/plan/plan_1.md). Первый следующий этап — техническая проверка доступных компонентов ERA и AIDE, среды исполнения и генератора кода.

## Принципы ведения работы

- Измерения и результаты фиксируются вместе с конфигурацией и ограничениями эксперимента.
- Решения по данным, метрикам, моделям и поисковым политикам заносятся в контекст до начала основных прогонов.
- Секреты, ключи API и персональные данные в репозиторий не добавляются.
